# Contributing to AI Agent for HPC

Thank you for your interest in contributing to the AI Agent for HPC project! We welcome contributions from the community to make these instructions more comprehensive and useful for everyone.

## Ways to Contribute

1.  **Add a new platform**: Submit instructions for an HPC system not yet covered.
2.  **Improve existing docs**: Fix errors, clarify instructions, or add new best practices.
3.  **Share your experience**: Open issues with suggestions, success stories, or common pitfalls you've encountered.

## How to Contribute

### Adding a New Platform

1.  Create a new file in the `docs/` directory.
2.  Follow the structure defined in `docs/template.md`.
3.  Name the file logically, e.g., `docs/<platform>-<institution>.md`.
4.  Submit a Pull Request (PR) with your new file.

### Improving Existing Documentation

1.  Fork the repository.
2.  Make your changes to the relevant markdown file.
3.  Verify that your changes are accurate and easy to understand.
4.  Submit a Pull Request.

## Pull Request Guidelines

-   **Descriptive Title**: Give your PR a clear and descriptive title.
-   **Context**: Explain what you changed and why.
-   **Verification**: Mention how you verified the information (e.g., "Tested on Cluster X").
-   **License**: Ensure you have the right to share the information.

## Style Guide

-   Use clear, concise language.
-   Use standard Markdown formatting.
-   Use code blocks for commands and scripts.
-   Include "What NOT to Do" sections where appropriate to prevent common errors.

## Code of Conduct

Please note that this project is released with a [Code of Conduct](CODE_OF_CONDUCT.md). By participating in this project you agree to abide by its terms.
